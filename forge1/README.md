# The Forge 1

The original game, kept unchanged for reference. Open `index.html`.

It is a Canvas2D pixel-art mining / forging / combat game at 480×270: hub, three mine floors,
one boss, procedural placeholder art. [The Forge II](../) in the parent directory is a
ground-up rebuild of the same loop — the mine generator here is the one it still uses.

- `index.html` — the game
- `tests.html` — its own logic tests and scripted smoke playthrough
- `shot.html#hub|cave|cave2|forge|hammer|bag|enchant|title` — single-scene renders
- `js/` — the source
